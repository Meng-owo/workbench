联网搜索源 · Tavily

输入区点亮「联网」且已填 key 时，发送前会先向 Tavily 检索，再把摘要注入对话。未配置则只提示去设置，不会装已搜索。

图像生成 · OpenAI 兼容

工具箱点「图像生成」：已配置则按输入框文案 POST {base}/images/generations 真出图；未配置只引导来这里。结果在对话里可预览/下载。

语音合成 · OpenAI 兼容

工具箱点「语音合成」：读输入框文本 POST {base}/audio/speech 生成 mp3，可播放/下载。未配置只引导。

视频生成 · 提交+轮询协议

协议（写死）：POST {base}/videos/generations 提交（body: model/prompt），立即带 url 则直取；否则 GET {base}/videos/{id} 按间隔轮询到 done/failed。结果页内可播+下载。未配置只引导。

节点同步 · 网关

工具箱点「节点」时 POST {base}/v1/subs/sync 触发同步，返回节点概况。未配置只引导。

听歌 · 音乐网关

工具箱点「听歌」用输入框关键词搜索 → GET {base}/v1/music/search?q=；结果可点播 → GET {base}/v1/music/play?id= 返回音频 url 页内播放。cookie/key 不进前端。

文件处理 · 本机 + 可选 PDF 网关

工具箱点「文件」选本机文件：文本/Markdown 预览摘要、图片尺寸、CSV 前几行表格化，均在本地完成。PDF 需网关 POST {base}/v1/files/extract，未配网关时如实提示。

测站 · 浏览器直连 + 可选网关

工具箱「测站」= 单 URL 延迟（读输入框）；「站点体检」= 多目标（默认列表 + 输入框追加）。浏览器直连受 CORS 限制，有网关优先走 POST {base}/v1/probe。
